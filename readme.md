# Dosa Restaurant API

## Purpose
This project is a REST API backend for our dosa restaurant. It provides access to three main objects: customers, items, and orders.

## Tech Stack
- Database: SQLite (file: db.sqlite)
- Framework: FastAPI
- Initialization Script: init_db.py (initializes database with relational constraints based on example_orders.json from midterm project)
- Main API: main.py

## Features
- CRUD operations for customers, items, and orders.
